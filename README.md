# 今夜最亮星 / Brightest Tonight

一个根据用户当前位置与当地时间，计算今晚最亮恒星并提供寻找方向的移动端 Web 产品。

## 已实现

- GPS 定位与手动城市降级路径。
- 白天自动寻找今晚入夜时刻，夜间显示此刻天空。
- 基于 Astronomy Engine 的恒星高度、方位、太阳与月光计算。
- 结合有效亮度、天空高度和云量的 Top 5 排名。
- 未来四小时的时间切换。
- 恒星详情、寻找方法和娱乐性「今日星语」。
- 用户输入生日月日后，本地判断西方太阳星座并生成今日星运。

## 隐私

- 精确 GPS 只保存在页面内存，不写入 URL、分析日志或持久存储。
- 天气请求只使用约 0.1° 精度的模糊坐标。
- 生日只需要月和日，只在浏览器内计算，不上传、不保存。
- 星语与星运均为娱乐内容，不构成现实决策建议。
